## 🚀 Sobre mim

Atualmente estudo Tecnologia da Informação na UNIVESP e venho aprofundando meus conhecimentos em desenvolvimento de software, automação, infraestrutura e experiência do usuário.

Também tenho uma forte base em multimídia e design, o que influencia diretamente a forma como construo interfaces, organizo projetos e penso na experiência final do usuário.

Hoje meus principais focos são:

- ⚙️ Desenvolvimento de aplicações desktop e web
- 🖥️ Automação e gerenciamento de servidores
- 🎨 UI/UX com visual moderno e nativo
- ☁️ Infraestrutura, deploy e distribuição de software
