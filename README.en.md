## Selected projects

### [Miguel Downloader](https://github.com/ogabriels2/MiguelDownloader)

A Windows application built with **C#/.NET 8 and WPF**, with a persistent queue, SQLite history, format selection and verification of the downloaded file. The repository contains source code, automated tests, continuous integration, and documentation of decisions and limitations.

I lead this project using AI-assisted development: defining requirements and expected behavior, reviewing changes and validating the application in use.

### [Força Aliada — Manager and Community](https://ogabriels.com/en/forca-aliada)

My most extensive project: an ecosystem bringing together server operations, a desktop application and a social platform. **Manager** uses Electron to organize servers, backups and control between computers; **Community** brings together profiles, posts and interactions on a web platform using Node.js/Express and PostgreSQL.

As the founder, I lead product vision and priorities, technical decisions, integrations, infrastructure, testing and coordination of collaborators. The community began in 2021; the technology initiative began in **November 2025**. The products remain under active development and continue to evolve.

Manager's public repository is a **distribution channel**, not its source code. The interfaces, guides, releases and portfolio account of my contribution provide public evidence of the work.
